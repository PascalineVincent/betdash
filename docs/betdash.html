Score de confiance

0–100 basé sur la forme, H2H, stats offensives/défensives, absents et value bet. Vert ≥ 68, orange ≥ 48.

Mise Kelly ¼

Critère de Kelly divisé par 4. Conservateur, ne dépasse jamais ton plafond de mise max.

Value bet

Positif = le bookmaker sous-estime la probabilité. C'est le signe d'une cote intéressante.

Forme (VVNDV)

V=3pts, N=1pt, D=0pt. Score = moyenne pondérée sur les matchs saisis.
